# wannacry-survey-evidence

Evidence repository for the survey paper *WannaCry Ransomware: A Review of Analyses, Defences and Impact Studies, 2015 to 2024*.

- **Course:** Foundations Of Cybersecurity (CSE25305), B.Tech (CSE) Semester 3, IILM University, Gurugram
- **Team:** T-02, Kanishk Jain and Krishna Preman
- **Supervisor:** Dr. Abhishek

The repository replaces the source-code repository that a build project would submit.

## Files

| File | Contents |
|---|---|
| `literature_matrix.csv` | One row per work read. Each row gives the reference number in the paper, its category, the problem, method, data or test bed, measure, main finding and limitation, the team member responsible, and whether it has been read. |
| `reference_library.ris` | The paper's 38 references in RIS format, for import into Zotero or Mendeley. The full IEEE citation is in each entry's note field. |
| `search_log.csv` | Each search string with the source, filters, date, number of hits and who ran it. Searches that a site's bot check blocked are marked as still to be run by hand. |

## Review at a glance

- **Works included:** 38. Of these, 32 are grouped into three categories and 6 are earlier ransomware surveys used as context.
- **Categories:**
  - A. Malware analysis (10 works), reviewed by Kanishk Jain
  - B. Defence and recovery (12 works), reviewed by Krishna Preman
  - C. Impact and attribution (10 works), reviewed by Kanishk Jain
  - Context surveys (6 works), reviewed by Krishna Preman
- **Period:** 2015 to 2024.
