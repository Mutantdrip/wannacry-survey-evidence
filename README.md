# wannacry-survey-evidence

Evidence repository for the survey paper *WannaCry Ransomware: A Review of Analyses, Defences and Impact Studies, 2016 to 2024*.

- **Course:** Foundations Of Cybersecurity (CSE25305), B.Tech (CSE) Semester 3, IILM University, Gurugram
- **Team:** T-02, Kanishk Jain and Krishna Preman
- **Supervisor:** Dr. Abhishek Pandey

The repository replaces the source-code repository that a build project would submit.

## Files

| File | Contents |
|---|---|
| `literature_matrix.csv` | One row per work read. Each row gives the reference number in the paper, its category, the problem, method, data or test bed, measure, main finding and limitation, the team member responsible, and whether it has been read. |
| `reference_library.ris` | The paper's 40 references in RIS format, for import into Zotero or Mendeley. The full IEEE citation is in each entry's note field. |
| `search_log.csv` | Each search with its source, query, filters, date, number of hits and who ran it. This covers the two database searches, the vendor and government sites, and the supplementary targeted searches for recent work. |

## Review at a glance

- **Works included:** 40, published 2016–2024, 15 of them from 2021 onwards.
- **Categories:**
  - A. Malware analysis (9 works), reviewed by Kanishk Jain
  - B. Defence and recovery (15 works), reviewed by Krishna Preman
  - C. Impact and attribution (12 works), reviewed by Kanishk Jain
  - Context surveys and threat-landscape reports (4 works), reviewed by Krishna Preman
